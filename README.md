## Overview
This repository contains an end-to-End Computer Vision pipeline engineered to perform real-time object detection and action recognition on video streams. The framework facilitates the generation of custom action data, robust model training (LSTM & Transformers), and real-time inference.

**Key Highlights:**
* Engineered a Computer Vision pipeline using PyTorch and OpenCV to perform real-time object detection and action recognition.
* Handled extensive data preprocessing and augmented image datasets to train and evaluate Deep Learning models.
* Integrated MediaPipe for holistic pose and keypoint extraction to significantly improve validation accuracy.
